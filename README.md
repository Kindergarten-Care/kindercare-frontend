## ✨ Technology Stack

The project is built with a modern tech stack to ensure performance and scalability:

- **Frontend Framework:** [Next.js](https://nextjs.org/) (App Router)
- **UI Library:** [React 19](https://react.dev/)
- **Styling:** [Styled Components](https://styled-components.com/) (CSS-in-JS)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Data Fetching:** [Axios](https://axios-http.com/)
- **DevOps:** [Docker](https://www.docker.com/), [GitHub Actions](https://github.com/features/actions)

## 🛠️ Installation & Setup

### 1. Prerequisites
- Node.js 18.x or higher
- npm / yarn / pnpm

### 2. Install Dependencies
```bash
npm install
# or
yarn install
```

### 3. Run Development Server
```bash
npm run dev
# or
yarn dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to see the results.

### 4. Build for Production
```bash
yarn build
yarn start
```

---

## 🐳 Dockerization

We provide a pre-configured Docker setup for easy deployment:

**Build Image:**
```bash
docker build -t kindercare-frontend .
```

**Run Container:**
```bash
docker run -p 3000:3000 kindercare-frontend
```
