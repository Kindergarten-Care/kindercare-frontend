# KinderCare Agent Hub

Welcome, Agent. To maintain the high standards of the KinderCare project, you MUST follow the defined rules and workflows.

## 🛠 Core Rules
- **Mandatory Architecture**: Follow [PROJECT_STANDARD.md](../PROJECT_STANDARD.md).
- **Clean Architecture**: Separation of Presentation, Logic, and Infrastructure.
- **Strict Typing**: No `any` allowed.

## 🎨 Design to Code Workflow
When working with Figma MCP to implement UI, follow this mandatory skill:
- [Figma to Code Workflow](./workflows/figma-to-code-workflow.md)

## 🚀 Commands
- `yarn dev`: Start development server.
- `yarn lint`: Run code quality checks.
- `yarn build`: Verify production build.

## 📂 Key Directories
- `src/app`: Routing & Server Components.
- `src/views`: Feature UI assemblies.
- `src/UIKit`: Atomic UI components.
- `src/services`: Business logic & API mappers.
